# Command-Line To-Do App

A simple to-do list built with Python. Tasks are saved to a JSON file, so they are still there the next time you run it.

## Features
- Add, show, and delete tasks
- Saves tasks to todos.json
- Handles a missing file and invalid input with try/except

## Run it
python todo.py

## What I learned
Functions, lists, loops, JSON file handling, and error handling.
